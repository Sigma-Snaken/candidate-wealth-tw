# 候選人財產申報資料庫

資料庫由 `pipeline/build.py` 產生，不放在 repo 裡：網站的「下載」連結有最新版的 `candidate_wealth.sqlite` 與每張表的 CSV（內容相同）。每張表都以 `year`（115 或 111）＋ `seq`（115 年中選會申報表編號）識別一位候選人；111 年資料以「同縣市、同姓名」對到 115 年的 `seq`（見 `match_111_115`）。

## 金額欄位的三種口徑
- `declared_*`：候選人在申報表上自己寫的數字（含自己用的匯率換算結果），原樣保留。
- `declared_totals`：申報表上印的各分項「總金額／總申報筆數」，也就是候選人自己認知的加總。
- `std_*`：外幣一律以臺灣銀行牌告「即期買入與賣出的中價」重新換算。115 年用 2026-10-16，111 年用 2022-09-02（與股價基準日相同），匯率表在 `fx_rates`。
- `market_twd`：證券以基準日收盤價重算（台股），外幣證券以統一匯率重算；查不到收盤價者等於申報值。
- 不動產估值（`est_*`、`realestate_*`）：本站依實價登錄算的參考值，不是申報資料，也不計入 `net_worth_*`；只有 `counted=1` 的列計入合計。見下方「不動產估值」。

## 外幣欄位
| 欄位 | 說明 |
|---|---|
| currency_raw | 表上幣別原文 |
| currency | ISO 代碼；表上未寫時由名稱或金額反推 |
| currency_source | declared（表上寫明）、name（由證券名稱判斷）、inferred（由金額比例推得）、default（視為新臺幣） |
| foreign_amount | 外幣金額 |
| declared_rate | 候選人使用的匯率 |
| rate_source | stated（表上明寫）、derived（新臺幣金額 ÷ 外幣金額反推）、unknown（外幣欄無法使用，改用申報期間臺銀中價推算外幣金額） |
| declared_twd_filled | 表上只寫外幣、新臺幣欄空白時，本站以申報期間臺銀中價補算的值 |
| std_rate / std_date / std_twd | 統一匯率、其日期與換算結果 |

## 主要資料表
candidates、summary、declared_totals、deposits、cash、securities（股票、基金、債券、其他）、land、buildings、vehicles（廠牌型號、汽缸容量、牌照、取得資料）、ships、aircraft、insurance、debt_claims、debts、business_investments、other_assets、validation_issues（明細加總與表上總額不符）、fx_rates、stock_prices、lvr_unit_prices、match_111_115。

## 不動產估值
來源是內政部不動產交易實價查詢服務網的[開放資料](https://plvr.land.moi.gov.tw/DownloadOpenData)，只用不動產買賣（a 檔，不含預售屋、租賃）。由 `pipeline/lvr.py` 彙總成單價分位數（`data/prices/lvr_*.json`，規則全文在其 `meta.rules`），只到段（小段）與路名，不含地號、門牌；`pipeline/realestate.py` 再對到每筆申報。

**成交資料**
- 季別：115 年用 114S1–115S3、111 年用 110S1–111S3 發布的資料（`summary.lvr_seasons`）。交易日期限第一季的前一年 1 月 1 日到股價基準日（115 年 1130101–1151016，111 年 1090101–1110902），排除遲延登記的舊案與誤植日期。
- 排除備註含：親友、特殊關係、協議價購、政府機關、標讓售、標售、急買急賣、債權債務、債務抵償、瑕疵、畸零地、公共設施保留地、含未來興建房屋成本、合建、包含其他買賣登記案件、民情風俗、水利地、容積代金、地上權、重建或重劃、都更；土地另排除：土地及建物分件登記、未登記建物、農作物、農業設施。也排除沒有鄉鎮市區的交易。
- 土地單價 ＝ 總價 ÷ 土地移轉總面積（交易標的為「土地」），限 10–10,000,000 元/m²；所有地號同一段小段才歸入該段。
- 建物單價 ＝（總價 − 車位總價）÷（建物移轉總面積 − 車位移轉總面積）（交易標的為房地，已含土地持分），限 1,000–10,000,000 元/m²；車位總價為 0（車位含在總價裡）時改用 總價 ÷ 建物移轉總面積。
- 去重：土地以成交的地號組合（段＋地號，只在程式內比對、不輸出）辨識，同一組地號在同一彙總鍵內只計一筆，多次成交取單價中位數；沒有地號的土地與房地，同一彙總鍵內同一交易日、同一單價（取整）的多筆視為同一批分割出售，只計一次（減少的筆數見 `meta.counts.batch_dup_*`）。
- 大面積土地：土地移轉總面積達 1,000 m² 的成交另計入 `SL`／`S0L`／`TL` 鍵。
- 段名正規化（兩邊相同）：去括號、阿拉伯數字轉國字、空白或 0 小段去掉、塩→鹽、双→雙、台→臺；申報的段名在實價資料裡找不到時，嘗試後／后、只寫小段、金門 劃／測段、宜蘭 X段一小段→X一段 等寫法，唯一命中才採用。

**對到申報**
- 層級依序：段（含小段，至少 3 筆）→ 段（不分小段，至少 5 筆）→ 路名（只限建物，至少 3 筆）→ 鄉鎮市區（至少 5 筆）。持分面積（`owned_area_m2`）達 1,000 m² 的土地改走 段(大面積)（3 筆）→ 段(不分小段,大面積)（5 筆）→ 鄉鎮市區(大面積)（5 筆）；只對到 鄉鎮市區(大面積) 的列填有 `est_*` 但標為 `large-land`、不計入，都不夠就不估。土地鍵的 p75 不超過 p25 的 1.01 倍（多半是同一賣方的分割出售）視為成交不足，改用下一層。
- 土地只有對到 段、段(不分小段)、段(大面積)、段(不分小段,大面積) 才可能計入：只對到 鄉鎮市區 的標為 `town-only`；所用鍵的 p75 超過 p25 的 5 倍（多半是農地與建地、工業區成交混雜）標為 `mixed-zone`；兩者都填有 `est_*` 但不計入。建物對到任一層級都可計入。
- 坐落只寫縣市與路名（例如「台北市長安西路」）時，路名只出現在一個鄉鎮市區就用它；出現在數個時，取同一位候選人其他坐落明寫的鄉鎮市區，仍無法決定就標 `ambiguous-town`。
- 網站「依據」欄：對到段級（段、段(不分小段)、含大面積）標「可查到實價登錄」，對到路名或鄉鎮市區標「用區段推估」。
- `est_twd` ＝ 單價中位數 × 持分面積，`est_low`／`est_high` 用第 25／75 百分位數。
- 基地（`flag='base'`、`in_building=1`）：土地依持分面積由小到大，併入一筆計入合計的建物：(1) 與建物同一天取得，且在同一段（不分小段）；建物沒寫段時看同一鄉鎮市區；(2) 建物有寫段、取得原因為自建、新建、第一次登記、建造，土地在同段、取得日在建物取得日當天或之前（兩邊都要有取得日期，土地要有持分面積）。每筆建物最多併入其持分面積 1.5 倍的土地，(1)(2) 共用這個額度，放不下的土地不視為基地；沒有持分面積的土地不佔額度，同一天取得即視為基地。`joint`、`share-check` 的列不併入基地。
- 只有 `counted=1`（有估值且 `flag` 為空）的列計入合計。要自己加總請用 `WHERE counted=1`；`flag` 非空的列仍可能填有 `est_*` 供參考。

| flag | 意思 | est_* |
|---|---|---|
| base | 建物的基地，價值已含在建物單價 | 多半有；沒有持分面積（或持分面積極小）、對不到行情的沒有 |
| large-bldg | 建物持分面積超過 1,000 m²（多半是非住宅或持分有誤，房地單價不適用） | 有，僅供參考 |
| garage-share | 疑似是整個共用部分的持分：(1) 同一筆 1,000 m² 以上的面積以不同權利範圍列了數次，或權利範圍的分子是另一列的分母（車位比例），與其他列重複；(2) 共用部分的列（坐落、取得價額或原因寫「共同使用部分」，或權利範圍不到 1/1、面積 300 m² 以上，且同段同一天有一筆持分面積較小、權利範圍 1/1、取得價額包含本列金額的列），持分面積超過本人同段其他非共用部分列合計的 2.5 倍 | 有，僅供參考 |
| large-land | 持分面積 1,000 m² 以上的土地，只對到 鄉鎮市區(大面積) 的行情，或大面積成交不足 | 前者有，僅供參考；後者無 |
| town-only | 土地只對到 鄉鎮市區 的行情（校準誤差過大，見下） | 有，僅供參考 |
| mixed-zone | 土地所用鍵的 p75 超過 p25 的 5 倍，同段成交價差異過大（多半是農地與建地混雜） | 有，僅供參考 |
| joint | 公同共有（權利範圍、坐落或取得價額欄寫「公同共有」，或寫成「公開共有」「共同共有」；或所有人欄寫公同），持分不是本人的 | 有，僅供參考 |
| share-check | 權利範圍疑似寫反（如 3/1，以 1/3 估） | 有，僅供參考 |
| no-share | 對到行情但沒有持分面積（權利範圍無法判讀或沒寫面積） | 無 |
| no-match | 坐落對不到，或各層級成交都不夠 | 無 |
| ambiguous-town | 段名存在於數個鄉鎮市區，申報內容無法判斷是哪一個 | 無 |

這是依地段行情的粗估，沒有考慮樓層、屋齡、地形、使用分區，不是鑑價。以 598 組買賣取得、在申報年前 3 年內取得、申報表寫有取得價額且各列都計入合計（或併入建物）的不動產校準：對到同一段的建物（房地），估值與申報取得價額的中位數比值為 1.01，61% 落在 0.67–1.5 倍之間；全部建物為 1.04、56%。土地（現在只計入對到段的估值）較差，中位數比值 1.16，只有 40% 落在 0.67–1.5 倍；其中對到段的大面積土地為 1.08、50%。前一版校準（740 組）中退到鄉鎮市區的一般土地最差（0.93 倍，僅 24% 落在區間內），只對到鄉鎮市區行情的大面積土地更早的校準也多半高估（中位數 1.72 倍，僅 17% 落在區間內），所以改標 `town-only`、`large-land` 不計入；含 `town-only`、`mixed-zone`、`large-land` 列的組（各 153、42、71 組，可重疊）不在上述樣本內。單筆誤差不小：一半的建物估值與申報價相差 1.42 倍以上，土地則是 1.75 倍以上；取得越早比值越高，部分是取得後的漲幅，新成屋則常被低估。

## 政黨
`candidates.party` 取自中選會「115 年地方公職人員選舉候選人登記名冊」（製表日期 115/09/07，`data/raw/cec_roster_115.json`，由 Gemini 3.5 Flash-Lite 轉錄），比對結果在 `data/parties_115.json`。`party_on_declaration_site` 是財產申報系統上的政黨欄，多數空白且有錯，只供參照。
